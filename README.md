# Grocery Deal Tracker

## Project Description
Grocery Deal Tracker is a proposed application that helps users save money by tracking grocery prices and notifying them when watchlisted products go on sale.

## Initial Requirements Elicitation
The initial requirements backlog was generated with assistance from OpenAI's ChatGPT and organized into GitHub Issues.

Each issue includes a requirement description, priority, category, acceptance criteria, and relevant dependencies.

## MVP Scope
The initial application will focus on user accounts, grocery product searches, watchlist management, price tracking, and sale notifications.

More advanced features, including price prediction, store distance preferences, and purchase urgency, are planned for future iterations.
